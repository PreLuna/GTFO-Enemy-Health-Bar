# EnemyHealthBar 说明

## 身份

- GUID：`PreLuna.EnemyHealthBar`；版本：0.4.0；类型：源码 managed。
- 主文档：[README](../README.md)；机器登记：[repo.json](../repo.json)。

## 功能

准星焦点敌人血条、最近命中副条、状态槽、Boss/MiniBoss 类型、自定义 profile 与 `EnemyHitApi`。伤害数字是独立子 MOD。

## ModControl

- 页面：`敌人血条`，8 个即时可写控件：总开关、最大距离、条宽、条高、透明度、显示名称、显示数值、状态槽。
- 通过 `EnemyHealthBarControlApi` 即时保存；不改其他键/注释。
- 本机 HUD，不写共享玩法状态。

## 依赖与兼容

- 无插件硬前置。
- 子 MOD `EnemyHealthBar.DamageNumbers` 硬依赖本 MOD 0.4.0。
- 未开放项：开关按键、护甲/结沫/弱点等开关、槽位上限等；当前只覆盖高信号视觉字段。

## 验证/安装

- 已安装 0.4.0；页面与滑块实际值曾由用户确认。
- 交付：`本地交付/当前/PreLuna.EnemyHealthBar/`。

## 边界

不覆盖全部 13 个配置项；爆炸/火焰伤害、特殊 profile 和联机组合以 README 为准。
