## 1. 面板能力边界

`ModControl` 0.3.4 可写目标支持四种值：

| Kind | 面板控件 | 适合的设置 |
| --- | --- | --- |
| Boolean | 开关 | 启用/替换/静音/确认音等 |
| Number | 滑块 | 音量、增益、尺寸、寿命、阈值 |
| Integer | 滑块 | 上限、索引、模式 |
| String | 目标值 | 颜色 hex；面板控件为 TheArchive `SColor` 拾色器 |

字符串只用于颜色；`Sound/CustomDirectory`、`General/ToggleKey` 仍留 cfg/只读。
`Style` 用 Number `styleIndex`（0=BF1、1=BF5、2=BF6），`TierSource` 用 Boolean
`healthTiering`（false=EnemyType，true=Health）映射，配置里仍保存字符串。

运行时大部分属性是**每次读取 ConfigEntry**，所以写入 cfg 后无需重启即可生效。
例外：颜色在初始化时解析成 `Color`；`CustomDirectory` 在初始化时建素材根目录。
（本次接入不开放这两个，所以不构成阻塞。）

## 4. 颜色拾色器怎么用

1. 点颜色行右侧的 `Pick Color`；TheArchive 打开右侧 `Color Picker`。
2. 拖 **Hue / Saturation / Value** 三个滑块，色块实时预览；粗略调色只需这三个值。
3. 点 **Apply** 生效；点 **Cancel** 放弃。Hex 输入框是可选精确输入，不需要就留空。
4. BFV 页已关闭 26 项全量“当前生效/已保存”长文本，只显示项数，避免文字重叠。
因为所有项都是即时自动保存，没有草稿/确认步骤，全量摘要不再承担“核对未保存值”的职责。

## 5. 只读状态（页头 FLabel / 诊断）

这些不写 cfg，只展示：

- 本 MOD 版本、目标状态（Available/Unavailable）。
- WinMM 后端：`opened=True/False`、设备失败次数。
- 素材：`base cues 6/6`、`icons 7/7`、素材根目录/自定义目录。
- 当前风格名、当前档位来源（EnemyType/Health）。
- 当前生效值/已保存值（面板现有 `CurrentValues`/`SavedValues` 惯例）。
- 最近一次命中/击杀诊断（可选）：limb 类型、EnemyType、HealthMax、tier、播放的 cue。
- `CustomDirectory`、`ToggleKey` 只读展示。

## 6. 已实现内容（0.2.0 + ModControl 0.3.4）

1. **修 `ReplaceVanilla`**：两个 indicator 前缀改为 `handled && ReplaceVanillaMarker`；
   关掉后 BFV 线/音仍画/播，但原版标记也保留。
2. **BFV `Control/`**：
   - `BfvFeedbackControlModels`（含 String kind，颜色以 hex 字符串传目标）；
   - `BfvFeedbackControlFileStore`（行级保存、哈希冲突检测、注释/未知键保留）；
   - `BfvFeedbackControlState`（26 项、saved/effective、revision、Validate/SetPersistent）；
   - `BfvFeedbackControlApi`（GetSnapshot/Validate/SetPersistent + JSON）。
3. **Plugin**：`EnsureControlState()`、`Config.SaveOnConfigSet=false`；`styleIndex` ↔
   `BF1/BF5/BF6`、`healthTiering` ↔ `Health/EnemyType`；四色实时刷新；颜色在 ModControl
   页用 `SColor` 拾色器，`TargetValueReader` 转 hex 交给目标 API。
4. **ModControl**：`BfvFeedbackAdapter` + factory、`BfvFeedbackConfig` 26 项、
   `InstalledModsSettings.BfvFeedback`、单列 `TargetPageBinding("BfvFeedback", "BFV 反馈")`。
5. **回归**：BFV 5 套 44 项（含控制 API 4 项）；ModControl 18 套（含 BFV 适配器 2 项）。
6. **交付**：BFV DLL + ModControl DLL + 现有 Assets；父 MOD 不动。
